# Oxono — rapport

Rapport de projet du cours d'intelligence artificielle (UCLouvain, groupe 114) sur les agents jouant à **Oxono** : minimax, MCTS, MCTS PUCT et AlphaZero.

Le code est dans [OxonoProject](https://github.com/SogliuzzoL/OxonoProject).

## Contenu

- `main.tex`, `references.bib` — source LaTeX ;
- `main.pdf` — version compilée ;
- `images/` — logos et figures.

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```
